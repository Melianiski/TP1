# Trabajo Práctico 1 — Informática General

## Descripción del proyecto

Este es el Trabajo Práctico 1 de Informática General, de la carrera de Artes Multimediales (UNA). Consiste en armar un sitio web con tres juegos, uno de cartas, uno de dados y uno de preguntas, usando HTML, CSS y JavaScript, aplicando los contenidos que vimos durante la cursada.

Los alumnos que forman parte del grupo son: Andrés Ruarte y Rocío Sosa.

### Primera etapa: estructura y layout

Durante esta primera etapa se definió en conjunto la estructura general del sitio, tomando como punto de partida la página principal (`index.html`).

Se acordó organizar la página de inicio de la siguiente manera:

- Barra de navegación principal.
- Sección de información general sobre el proyecto.
- Sección destinada a presentar los tres juegos.
- Imágenes de cada juego que funcionan como enlaces hacia sus respectivas páginas.
- Pie de página con información de la materia y acceso a la sección "Nosotros".

La distribución visual de los juegos con respecto al layout del index se planteó colocando los tres juegos en una misma fila, utilizando sus respectivas imágenes como elemento principal de acceso haciendo clic.

La sección "Nosotros" será desarrollada por Rocío y se incorporará posteriormente al proyecto.

La estética y algunos aspectos visuales del sitio todavía se encuentran en desarrollo, por lo que podrán modificarse a medida que avance el trabajo.
